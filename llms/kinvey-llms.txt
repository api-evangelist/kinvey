# Kinvey

> Kinvey was a mobile Backend-as-a-Service (BaaS / mBaaS) platform providing data storage, user management, file storage, push notifications, and serverless business logic (Flex) for web and mobile apps. It was acquired by Progress Software and its standalone developer surface has since been retired: kinvey.com redirects into Progress, the developer/docs subdomains no longer resolve, and the GitHub organization was archived on 2025-02-13. Published client SDKs and the CLI remain available on their package registries.

## Status
- Retired / absorbed into Progress Software. See lifecycle/kinvey-lifecycle.yml.
